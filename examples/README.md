# Examples

Sample scripts for running the engine programmatically.

| Script | Description |
|--------|-------------|
| `run_improvement_loop.py` | Run VSR from `config/example.yaml` |
| `run_benchmark.py` | Invoke benchmark harness |
| `improve_operator_prompts.py` | Evolve bundled operator prompts |

```bash
pip install -e ".[all]"
python3 examples/run_improvement_loop.py
```

For CLI usage, see [docs/getting_started.md](../docs/getting_started.md).
